# JV-Link接続確認（2026-09-21）

ユーザーによる64bit版JV-Link導入後に確認した。
SDK本体は5.0.0（64bit）。公式PythonサンプルのCOM生成・初期化・読込み手順を確認し、同じCOMインターフェースをPowerShellから呼び出した。
公式検証ツールのGUIや公式サンプルGUI自体を実行した確認ではない。

## 実行条件

- ソフトウェアID: UNKNOWN（公式サンプルと同じ）
- API: JVInit → JVRTOpen → JVRead → JVClose
- データ種別: 0B41（単複枠の時系列オッズ）
- 対象: 2026-09-20 中山8R、要求キー2026092006040608
- レースの存在確認: [JRA公式レース結果](https://www.jra.go.jp/JRADB/accessS.html?CNAME=pw01sde1006202604060820260920%2F12)
- 読込制限: 30秒または2,000レコード。今回は上限前にEOFまで完了。
- JVReadの正数をレコード長としてCP932へ再符号化し、該当長の原文を保存。Unicode変換を介しているため、JVRead前の転送バイト列そのものと一致するとの保証は別途必要。
- -1はファイル切替、-3は短い待機、その他の負数は停止。終了時はJVCloseを呼び出す。
