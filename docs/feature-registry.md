## ロジスティック回帰の前処理（初期実装）

age / horse_number / runner_count / distance / carried_weightは学習データだけで標準化する。sex / bracket_number / surface / venueはカテゴリとして学習データだけでOneHotEncoderを適合する。未知カテゴリは既存カテゴリへ付け替えず、当該カテゴリ群をすべて0として扱う。欠損補完とは別の処理で、欠損入力自体は拒否する。

初期設定はL2、C=1、lbfgs、max_iter=1000。未収束はエラーにする。二値ロジスティックの出力をレース内合計で割って合計1の勝率を生成する。元の二値出力も診断用に保持する。この正規化で較正が保証されるわけではなく、今後既存指標で評価する。結果列は学習時の目的変数のみで、前処理へ渡す列は承認済み9項目に固定する。
