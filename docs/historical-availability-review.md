# 過去学習データの利用時点レビュー

2026-09-22。対象は承認済みlogistic-initial-v1。期間・9特徴量は変更しない。

## 確認できたこと

SDK同梱JV-Data仕様書4.9.0.1の提供タイミング表（PDF54ページ）では、RACEの出馬表版は確定レース情報発表まで、確定成績は1年間の提供。実際に2025-10-03提供分はJG375のみ、RA/SEなし。2025-10-06提供分は10/4・10/5開催48レースのRA7と686頭のSE7を取得できた。

従って、今から全学習期間の発走前原本をJVOpenだけで回収できるという前提は採用しない。過去取得時刻を遡らせたり、成績の作成日を発走前の公表時刻とみなしたりしない。

## 項目別の残る確認

- 年齢・性別・枠番・馬番・競馬場: レースに結び付いた値として取得可能。訂正履歴と、出馬表時点との一致の根拠が必要。
- 距離・コース種別・負担重量: 変更前値のフィールドも存在する。変更がある場合、変更発表時刻が不明なら締切時点の値を自動選択しない。変更前欄が0であるだけで、全改訂を通じ変更なしと断定しない。
- 頭数: 成績の実出走頭数は取消・除外を反映するのでそのまま使わない。締切時点の対象集合を復元する根拠が必要。
- ラベル: 確定着順と異常区分を利用する。下位同着と1着同着、非出走と競走中止を区別する。結果による対象の選別をした場合は選択の偏りを明示する。

10/4・10/5の標本では距離・トラック・負担重量の変更前欄に非ゼロ値なし、異常区分0が683頭、3が2頭、4が1頭。この標本から全期間に一般化しない。
