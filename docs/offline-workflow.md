# 契約・JV-Linkなしで進める範囲

2026-09-21のユーザー指示に基づくオフライン準備。無料体験を開始する処理はない。
Phase 0の環境演習に続き、市場ベースラインの受入れ・計算・評価を合成データで予行する。
Phase 0/1の実データ検証を完了扱いせず、Phase 2以降のモデル開発には進まない。

## 実行

docs/setup.mdの環境構築後、リポジトリ直下で実行する。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m shibata.offline demo --output-dir outputs/offline-demo
```

2回目は別の出力先を指定する。既存フォルダへの上書きは失敗させる。
デモは架空の3レース・6頭分・18オッズ行を生成する。2024/2025/2026という日付も架空で、学習・検証・Testの期間設定ではない。

既存ファイルを受け入れるコマンドも用意している。

```powershell
.\.venv\Scripts\python.exe -m shibata.offline run --input-dir data/interim/example --output-dir outputs/example-run
```

入力は[data-contract.md](data-contract.md)の内部形式が必要。JV-Dataをそのまま渡すことはできない。

## 処理順と出力

1. 入力5ファイルをraw/へコピーし、SHA-256を保存する。処理はコピー側を読む。
2. 列・ID・重複・数値・時刻・全頭数を検証する。
3. 予測締切以前の最新の中間オッズを、レース全体のスナップショット単位で選ぶ。
4. 市場勝率を計算し、predictions.csv / predictions.parquetへ保存する。
5. その後でresultsを読み込み、結果と予測のキーが完全一致するか確認する。
6. report.json、calibration.csv、year.csv、popularity.csv、odds_rank.csv、odds_band.csvを保存する。

report.jsonにはデータ版、入力・出力ハッシュ、ソースコードハッシュ、Gitコミット、未コミット変更の有無、Python・ライブラリ版、評価定義版を記録する。
status.jsonがPASSであることを確認してから利用する。FAILED時の予測ファイルは診断用であり、正式成果として扱わない。
生データ・予測・レポートはoutputs/配下に置き、Gitには追加しない。

## 時刻の扱い

- observed: 実際の取得時刻が予測締切以前であることを要求する。標準モード。
- historical: 後日取得した履歴を検証するため、公表時刻を使用する。dataset.jsonで証拠レビュー済みの明示が必要。
- historicalは「当時このPCで予測していた」証拠にはならない。公表時刻の根拠をコードが自動で保証することもない。
- 最終オッズはどちらのモードでも予測入力に選ばない。
- 最新の適格スナップショットが不完全なら停止する。古い完全な値へ黙って戻したり、馬ごとに時刻を混ぜたりしない。
- 同一発表時刻の異なる訂正版は曖昧として停止する。後勝ちで上書きしない。

## 評価定義 v1

既存の指標定義・期間を変更したものではなく、初めて集計単位を明文化した準備用定義。

| 出力名 | 定義 |
|---|---|
| binary_log_loss_per_runner | 全出走行で -[y log(p)+(1-y)log(1-p)] を平均 |
| binary_brier_per_runner | 全出走行で (p-y)^2 を平均 |
| winner_log_loss_per_race | 各レースの勝馬について -log(p) をレース平均（参考） |
| multiclass_brier_per_race | レース内で (p-y)^2 を合計しレース平均（参考） |
| Calibration | 0.1刻みの確率帯で平均予測確率と実勝率を比較。空区間の確率は欠損のまま |

対数は自然対数。二値指標は各出走行を等しく重み付けするため、頭数の多いレースの寄与が大きい。
人気別は同じスナップショットの提供元人気順位、odds_rank別は計算上の順位。同オッズの計算順位は同順位・最小順位とする。
オッズ帯は [1,2), [2,5), [5,10), [10,20), [20,50), [50,∞)。年度は日本時間の発走予定日。
校正は集計表まで。校正器の学習や未知データでの性能検証はまだ行わない。

ROIは購入ルールと公式払戻が未確定のためnullと理由を保存する。単勝オッズを実際の払戻として代用しない。
同着、取消による出走構成変更、返還、未確定結果は現段階で自動補正しない。これらを通常レースに見せかけず、別途扱いを決める。
