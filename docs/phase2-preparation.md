# Phase 2の開催前準備：3モデルの合成データ演習

準備日: 2026-09-23。Phase 1の市場ベースライン観測と独立した、Phase 2の操作確認。承認済みの9特徴量とTrain/Validation/Test期間は変更していない。ユーザーが合成データでのLightGBM・CatBoostの準備を指示した範囲で実行した。

## 実装と実行

既存ロジスティック回帰に加え、LightGBM 4.6.0とCatBoost 1.2.8の合成データ専用アダプタを用意した。数値の標準化とカテゴリの一覧はTrain2レースだけで学習し、Validation1レースには再適合しない。欠損、頭数・馬番の不整合、複数勝馬、Train外の日付を拒否する。各馬の二値確率をレース内で正規化し、既存v1指標を同じ馬集合・同じ市場行から計算する。Testは空のまま。

```powershell
.\work\phase0-build\Scripts\python.exe -m shibata.phase2_rehearsal --output outputs/phase2-synthetic-three-model-<新しい実行ID>
```

この環境はPhase 0の固定依存から作成済み。新規環境では`requirements-phase0-lock.txt`を使う。標準`.venv`はツリーモデルの任意依存を含まないため、このコマンドには使用しない。

コマンドは架空レコード12行の`synthetic-raw.json`を内部生成し、レース内の頭数を算出して承認済み9特徴量の`synthetic-features.csv`を作る。これはJV-DataのRA/SE原本パーサーを通す確認ではない。2レース8頭をTrain、後の1レース4頭をValidationへ分割する。実際のJRAデータ、観測中のオッズ、保存済みTest結果を読み込まない。

各モデルを学習・保存・ハッシュ検証付き再読込し、再読込予測と学習直後の予測を誤差1e-12以内で照合する。LightGBMはテキスト、CatBoostはCBMのネイティブ形式、前処理定義はJSONに保存する。モデル成果物はローカルoutputsにのみ保存しGitに含めない。ネイティブモデルと前処理JSONのSHA256を確認するが、ハッシュはデータの利用時点の証明ではない。

`comparison.json`と各モデルの`*-metrics.json`に市場・モデル・差分の指標を保存する。較正、人気、オッズ帯等の表も各モデルで同じv1評価処理から出す。`status.json`には入力・設定・成果物のハッシュ、対象数、`real_data_used=false`、`test_evaluated=false`、`phase_promotion=false`を残す。

## 検証結果と限界

実行ID`phase2-synthetic-three-model-v2`でCLIがPASS。関連26テストが成功し、Train外日付・欠損・不完全レース・勝馬不整合の拒否、未知カテゴリ、前処理がValidationで再学習されないこと、モデル改変の検出、同一市場母集団、別出力先での評価値再現を確認した。証拠はローカル`outputs/phase2-preparation-tests-v2/pytest.xml`。初回CLIは前処理出力が密行列だった場合の変換エラーで停止し、両形式対応後の新規出力先で成功。初回テストの1件失敗は、CatBoostのネイティブ保存ファイルのバイト一致を異なる学習実行間の要件にしていたことが原因。再実行の評価数値比較へ修正し、26件成功。

本演習の市場オッズは架空の固定値であり、3モデルの値の大小は競馬の予測性能を意味しない。学習コードは合成専用の設定を要求し、実データの学習可否やPhase 2昇格を判断しない。既存の過去成績参考実験も当時の入力時点を証明できていない。

## 実データ評価前の残作業

1. Phase 1の観測・終了判定を完了し、比較基準の対象と時点を確定する。
2. 学習用の過去レースについて、各特徴量が予測締切時点で利用可能だったこと、原本の対象期間・欠測・改訂を確認する。既存の事後復元標本を無条件で転用しない。
3. 実データ用の3モデル設定と原本→特徴量→学習→予測→評価の接続を、承認済み条件に沿って整える。前走特徴量は現時点の9項目に追加しない。
4. 全モデルを同じレース・馬・市場時点・v1指標で比較し、6項目のPhase終了判定を記録する。Testはモデル選択に使用しない。

比較報告時は各モデルの対象レース数・頭数、取得時点、欠測理由、4指標、較正・人気・オッズ帯の標本数、モデルと市場の差、限界を並記する。モデル間の差は同じ対象集合でのみ解釈する。
