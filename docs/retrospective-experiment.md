# 過去成績から復元する参考実験

2026-09-22、ユーザーが「参考実験として進めて良い」と承認。厳密な発走前観測とは別の実験として、初めて実データによるロジスティック回帰の学習・検証を実行した。

## 固定条件と限界

Train=2025-10-01〜2026-06-30、Validation=2026-07-01〜08-31、Test=2026-09-01〜09-13。9特徴量・C=1・評価指標は当初承認から不変。Testの原本はこの実行で読み込まず、期間外のレコードが渡された場合も停止する。初期の厳密な設定は変更せず、reference_training_enabledを持つ別設定でのみ実行する。

確定RA/SEから9項目を復元する。当時の公表時刻は証明できないため、pre_race_availability_verified=falseを保持する。頭数はRAの登録頭数・SE全頭集合から計算し、取消等のあるレースを丸ごと除外する。距離・コース・負担重量の変更前欄に値がある場合も除外する。変更前欄が空欄/0でも当時の値の保証にはならない。

完全な通常順位、同着なし、欠損なしを初期対象にする。確定O1の上限打切り・欠損がある場合も除外する。この選別は結果を参照するため、選択の偏りがある。各レースの採否、最初に該当した除外理由、原本ハッシュをrace-audit.jsonへ残す。全改訂を保存し、完全に同じバイト列のみ重複排除する。異なる改訂の自動的な最新版選択はしない。

着順はラベルだけに使用し、モデルには渡さない。市場比較には事後の確定O1を使用する。これは発走10分前の市場ベースラインでも、同じ情報締切による公平な性能比較でもない。結果確定時刻は作らず、確定結果をローカルで観測した時刻を記録する。

## 実行と出力

```powershell
.venv/Scripts/python.exe -m shibata.retrospective --manifest data/raw/jvopen-race-20251006.json --manifest data/raw/jvopen-race-20260727-v2.json --output outputs/logistic-retrospective-v1-sample
```

出力先は新規限定。設定・原本台帳・特徴量・ラベル・全対象採否・学習データ・モデル係数・検証予測・評価表をローカルへ保存し、status.jsonへ各SHA256を記録する。モデルの保存後再読込予測は元の学習済みモデルとrtol=1e-12で照合する。標準化とカテゴリ作成はTrainだけでfitする。
